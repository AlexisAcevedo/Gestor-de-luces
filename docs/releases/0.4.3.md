## Highlights in v0.4.3

- **IPC bridge and loopback HTTP server hardening.** Replaced direct `JsApi` object attribute exposure on `window.pywebview.api` with a `BlockedJsApi` wrapper paired with explicit `window.expose(*build_exposed_functions(js_api))` callables to prevent dotted `getattr` traversal from JavaScript. Hardened `NoCacheBottleServer` on `127.0.0.1` with a cryptographically random `secrets.token_urlsafe(24)` server ID, disabled `server.js_api_endpoint`, removed wildcard `Access-Control-Allow-*` CORS headers, restricted methods to `GET`/`HEAD`, added `Host`/`Origin` allowlisting and a `64 KiB` `Content-Length` limit, enforced strict `NaN`/`Inf`/`OverflowError`/`bool` bridge input validation, and added CSP (`frame-ancestors 'none'`) security headers.
- **Local UDP endpoint and atomic JSON storage hardening.** Consolidated strict `validate_local_endpoint()` validation across `cli.py`, persisted `bulbs.json` loading, and `WizUdpController` to reject `0.0.0.0`, `255.255.255.255`, multicast/broadcast, external targets, and unauthorized ports; moved `create_datagram_endpoint` inside `try` for leak-free error handling; and added file-size caps and strict schema validation in `JsonRepositories`.
- **Async stream lifecycles, WASAPI/MSS stability, and EMA convergence.** Guarded `SleepTimerManager`, `AmbilightStreamManager`, and `MusicSyncStreamManager` against restart races with monotonic generation/run IDs (`_generation` / `run_id`), split audio sampler teardown (`close_audio_sampler()` vs `close_all_resources()`), added `RotatingFileHandler` log rotation and stream error backoff, fixed EMA deadband stalls and non-finite smoothing inputs in `StreamRateLimiter`, and hardened WASAPI COM/session lifecycle locking, hot-unplug recovery, cached FFT buffers, and `mss` `ScreenShotError` boundaries.
- **Win32 handle hygiene and desktop shell concurrency.** Fixed `apply_window_icon()` `.native` handle unwrapping and cached `HICON` disposal (`release_window_icons()`), added explicit 64-bit `ctypes` `argtypes`/`restype`, `IsHandleCreated` guards in `winforms_host.py`, prior `Region` disposal in `winforms_paint.py`, and deterministic `SingleInstanceGuard` handle cleanup (`ERROR_ACCESS_DENIED`/`WAIT_FAILED`). Synchronized `DesktopApplication` behind `_state_lock`, `_menu_sync_cond`, and `_visibility_generation`, removed `gestor_luces.ports.interfaces` in favor of `LightControlServicePort`, hardened `BridgeLifecycle` shutdown behind `_loop_state_lock`, moved `TrayController` wakeups onto `_refresh_cond`, and tightened multi-monitor `WorkingArea`/high-DPI geometry clamping.
- **Resilient frontend bridge, delta polling, accessibility, and CSS performance.** Added late `pywebviewready` native bridge upgrades after the 2000 ms fallback, monotonic request sequencing, `dedupeKey` in-flight deduplication, lightweight delta polling (`get_ambilight_status`, `get_music_sync_status`), selective panel DOM updates with active-input focus protection, unnested interactive scene/fixture controls, keyboard-accessible `#color-wheel-canvas` navigation, `:focus-visible`/`forced-colors` support, compositor-only `scaleX` music meters, and scoped `backdrop-filter`.
- **Packaging, signing order, CI hardening, and bilingual documentation.** Signed `GestorDeLuces.exe` before archiving into the portable ZIP and Inno Setup installer with HTTPS RFC 3161 timestamping (`https://timestamp.digicert.com`), excluded helper `*.py` scripts (`make_icon.py`) from packaged `assets/`, updated `installer.iss` with `runasoriginaluser`, unconditional `HKCU\...\Run` uninstall cleanup, and bilingual EN/ES `[CustomMessages]`, pinned all GitHub Actions by 40-char commit SHA and Inno Setup to `6.7.1`, scoped `contents: write` strictly to `publish`, made `bandit` and `pip-audit` blocking CI gates, added Windows Git Bash auto-detection for workflow tests, and synchronized all six English/Spanish docs.

## Breaking changes

- Removed the internal `gestor_luces.ports.interfaces` re-export barrel; internal consumers now import `LightControlServicePort` (`gestor_luces.ports.light_control`), `repositories`, or `autostart` directly. No public CLI flag, UI workflow, or user configuration format changed.

## Tests and CI

- 362 Python tests and 128 JavaScript tests (`node --test`, zero npm dependencies, 86.60 % line coverage across all 9 `ui/js/` modules).
- CI on Windows runs Python 3.12 and 3.14 plus dedicated `js tests`: `ruff check`, blocking `bandit` (0 issues across 9,905 lines scanned) and `pip-audit`, and per-package coverage gates (`domain` ≥ 90 %, `application` ≥ 75 %, `adapters` ≥ 55 %).

## Known limitations

- One lost `getPilot` reply marks that bulb offline, so if every target drops the read at the same moment the tray offers "Turn on" while the bulb is already on. Label and action stay consistent, and it self-heals on the next poll.
- A live read can still overwrite a fresher optimistic write made in flight by another consumer for one cycle.
- The About box is a native message box without an owner window, so it appears as its own alt+tab entry while it is open.
