## Highlights in v0.8.0

- **Configurable Ease-In-Out Crossfade Transitions (`TransitionEngine`).** Added `TransitionEngine` (`application/transition_engine.py`) supporting smooth RGB and Kelvin fades (`0.0s` instant default or `0.5s–5.0s` configurable via `#transition-seconds-select`) with per-bulb preemption and automatic cancellation on stream start.
- **Hardware Capability Inference & Wi-Fi/Firmware Diagnostics.** Added `BulbCapabilities` and `infer_bulb_capabilities(module_name)` in `domain/models.py` plus live Wi-Fi `rssi` and `fwVersion` extraction in `WizUdpController`, displaying RSSI/firmware metadata in `#fixture-list` and gating RGB controls for tunable-white or dimmable-only bulbs.
- **Expanded CLI & Opt-In Loopback HTTP API (`LocalHttpApiServer`).** Added `--name`, `--data-dir`, `brightness`, `scene`, `preset`, and `zones` subcommands to `wiz_console.cli`, plus an opt-in `127.0.0.1` HTTP API (`WizConsoleLocalApi`, Bearer token checked with `hmac.compare_digest`, 16 KiB body cap, disabled by default).
- **Multi-Vendor LAN Foundation (Philips WiZ + Govee LAN).** Added `Bulb.protocol` (`"wiz"` | `"govee"`), `GoveeLanController` (`adapters/govee/lan_controller.py` over UDP 4003), `CompositeLightController` (`adapters/registry.py`), and `#manual-protocol-select` in `#add-bulb-dialog`.

## Breaking changes

- None. All v0.5.0–v0.7.0 JSON files load with defaults (`protocol="wiz"`, `transition_seconds=0.0`, `local_api.enabled=False`).

## Tests and CI

- Expanded Python and JavaScript test suites covering crossfade preemption, capability inference, RSSI/FW diagnostics, `--name`/zone CLI subcommands, Bearer-authenticated local HTTP endpoints, `WizConsoleLocalApi` thread teardown, and mixed WiZ + Govee LAN control against `FakeGoveeBulbServer`.
- CI on Windows runs Python 3.12 and 3.14 plus `js tests`: `ruff check`, `ruff format --check`, blocking `bandit` and `pip-audit`, and per-package coverage gates (`domain >= 90%`, `application >= 75%`, `adapters >= 55%`).

## Known limitations

- Govee LAN control requires Govee devices with LAN Control enabled in the Govee Home mobile app on the same subnet (`UDP 4003`).
