## Highlights in v0.7.0

- **Circadian Kelvin/Brightness Curve & Wake-Up Sunrise Ramp.** Added pure time-of-day cosine progression (`CircadianConfig`) and smooth sunrise ramp scheduling (`WakeupRampConfig`) in `domain/automation.py`, executed asynchronously inside `AutomationService` on the existing asyncio event loop with zero extra OS threads.
- **Opt-In Windows Session & Power Lighting Triggers.** Added `SessionMonitor` port (`ports/session_monitor.py`) and `WindowsSessionMonitor` (`WizConsoleSessionMonitor`) listening to Win32 `WM_WTSSESSION_CHANGE` and `WM_POWERBROADCAST` events so lights can power off on lock/sleep and restore their exact previous RGB/Kelvin/scene state on unlock or wake.
- **Opt-In Foreground Process Profiles & Local On-Air Indicator.** Added `ContextMonitor` port (`ports/context_monitor.py`) and local-only `WindowsContextMonitor` (`GetForegroundWindow` + Windows `ConsentStore` `microphone`/`webcam` active check) with On-Air priority override and automatic lighting restoration when leaving a call or tracked app.

## Breaking changes

- None. All v0.5.0 / v0.6.0 `bulbs.json`, `scenes.json`, `zones.json`, and `settings.json` configurations load cleanly with all new automation features disabled by default.

## Tests and CI

- Expanded Python and JavaScript test suites covering `CircadianConfig`, `WakeupRampConfig`, `SessionTriggersConfig`, `WindowsSessionMonitor` thread lifecycle, `WindowsContextMonitor`, On-Air/process precedence & restore, and `#automation-details` UI bindings.
- CI on Windows runs Python 3.12 and 3.14 plus `js tests`: `ruff check`, `ruff format --check`, blocking `bandit` and `pip-audit`, and per-package coverage gates (`domain >= 90%`, `application >= 75%`, `adapters >= 55%`).

## Known limitations

- On-Air and foreground process detection rely on Windows `ConsentStore` timestamps and `QueryFullProcessImageNameW`; elevated or UWP/sandboxed processes without query permission are skipped cleanly.
