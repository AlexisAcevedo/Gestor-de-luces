## Highlights in v0.6.0

- **User-defined Zones & Multi-Bulb Custom Scenes (`zones.json`, `bulb_states`).** Added `Zone` entities with atomic `JsonZoneRepository` persistence, one-click zone selection in `#zones-section`, `<dialog id="zone-dialog" closedby="any">` creation/editing, and automatic cascading reconciliation when fixtures are deleted or move IP via DHCP MAC matching. Extended `CustomScene` with optional per-bulb heterogeneous `bulb_states` (omitted when empty for full v1 JSON backward compatibility) and parallel `apply_custom_scene()` execution.
- **BUG-001 Tray-exit WinForms disposal hardening.** Guarded `_resolve_native_hwnd` against disposed WinForms `Form` handles (`IsDisposed` / `Disposing` / `IsHandleCreated` + `ObjectDisposedException` boundary), cached `id(window) -> hwnd` in `window_chrome._WINDOW_HANDLES` so cached `HICON` handles still release via `DestroyIcon`, and isolated every teardown step inside `DesktopApplication.cleanup()`.
- **Multi-Zone Ambilight & Cinema Letterbox Auto-Crop.** Added single-grab multi-region screen sampling (`full`, `left`, `right`, `top`, `bottom`, `center`) in `MssScreenSampler.sample_regions()` with automatic dark letterbox/pillarbox bar detection (`detect_letterbox_bounds`), per-bulb screen-zone mapping (`region_map`), and independent per-bulb EMA rate-limited streaming (`ServiceContext.stream_bulb_frames`).
- **Music Sync Per-Bulb Frequency Bands, Beat Onset Detector & Custom Palettes.** Added `BeatDetector` (rolling energy-history onset detector with 140 ms cooldown) and optional beat brightness pulse (`beat_boost`), pure domain per-band mapping (`full`, `bass`, `mid`, `treble`) in `domain/music_colors.py` for independent per-bulb reactivity, and a customizable 3-band hex `custom` palette persisted in `settings.json`. *(Optional PR 2A.5 DXGI/WGC backend was skipped because single-grab NumPy multi-zone slicing meets the 10 Hz latency budget with zero extra dependencies.)*

## Breaking changes

- None. All v0.5.0 `bulbs.json`, `scenes.json`, and `settings.json` configurations load cleanly with defaults for new fields.

## Tests and CI

- Expanded Python and JavaScript test suites covering Zones, Multi-Bulb Custom Scenes, BUG-001 disposed Form cleanup, multi-region Ambilight + letterbox cropping, `BeatDetector`, custom music palettes, and per-bulb frequency band assignment.
- CI on Windows runs Python 3.12 and 3.14 plus `js tests`: `ruff check`, `ruff format --check`, blocking `bandit` and `pip-audit`, and per-package coverage gates (`domain >= 90%`, `application >= 75%`, `adapters >= 55%`).

## Known limitations

- Win32 GDI `mss` capture may sample black frames on protected DRM video streams or exclusive fullscreen games.
